# Devlog

Log automatico delle sessioni Claude Code, generato dallo hook SessionEnd (`.claude/hooks/devlog.sh`). Ogni voce riporta macchina, branch, ultimo commit e modifiche non ancora committate a fine sessione. Non modificare a mano le voci esistenti: è un log append-only condiviso tra tutti i dispositivi (PC casa, PC portatile lavoro, sessioni web) che clonano/pullano questo repo.
