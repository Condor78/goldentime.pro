# GoldenTime Pro

App di gestione presenze dipendenti: timbratura entrata/uscita e importazione anagrafica da file CSV.

## Demo live

Pubblicata tramite GitHub Pages: https://condor78.github.io/goldentime.pro/

## Sviluppo locale

L'app è un singolo file HTML autonomo (`index.html`), senza dipendenze o build step. Basta aprirlo in un browser.
